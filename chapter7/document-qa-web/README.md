# Document QA Web

智能文档问答助手的独立 React 前端。

当前已完成阶段十一 Step 11.1～11.11：

- React + TypeScript + Vite 项目骨架；
- 本地环境变量与 `/api` 开发代理；
- 与 Fastify 后端对应的 TypeScript HTTP 契约。
- PDF 上传、入库状态与错误提示；
- 当前文档的单轮 RAG 问答、引用和警告展示。
- 学习助手追问与学习笔记保存。
- 当前会话统计与学习记忆检索。
- 浏览器内学习报告摘要（不暴露后端文件路径）。
- 上传、问答、笔记、检索和报告的一条前端工作流集成测试。
- 跨模块统计自动刷新、键盘焦点与加载状态无障碍支持。

## 本地开发

后端默认运行在 `http://127.0.0.1:3000`，前端默认运行在
`http://127.0.0.1:5173`。

```bash
npm install
npm run typecheck
npm run dev
```

开发环境中，浏览器对 `/api/*` 的请求会由 Vite 代理到 Fastify 后端。

## 验证与构建

```bash
npm test
npm run build
```

完整人工验收顺序：

1. 启动后端、其依赖服务和前端开发服务器；
2. 上传可解析的 PDF，确认当前文档和统计自动更新；
3. 完成一次文档问答，检查回答和引用来源；
4. 使用学习助手追问并保存一条笔记；
5. 检索该笔记，并生成浏览器内学习报告；
6. 用键盘 `Tab` 从页面顶部移动焦点，确认会出现“跳到主要内容”，且所有输入框和按钮均可操作；
7. 在窄屏宽度下确认卡片纵向排列、没有横向滚动。

## 安全边界

只有可以公开到浏览器的配置才能使用 `VITE_` 前缀。LLM、Embedding、
Qdrant 和 Neo4j 的密钥必须只保存在后端项目中。
